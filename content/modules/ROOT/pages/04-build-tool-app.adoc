= Module 4: Build a Tool-Calling Application

_Estimated time: 15 minutes_

In this module you will write a Python script that defines multiple tools, sends a user query to the model, detects and executes tool calls, and returns the results for a final answer. This is the pattern used in production tool-calling applications.

== The Application Pattern

In Module 3 you ran each step manually. A real application automates the loop:

1. Send the user's message with tool definitions
2. Check if the model wants to call tools
3. If yes, execute each tool and collect results
4. Send results back to the model
5. Repeat until the model responds with a final answer (no more tool calls)

== Write the Script

Create the tool-calling application:

[source,bash,role="execute"]
----
cat > ~/tool_app.py << 'PYEOF'
import json
import os
from openai import OpenAI

# --- Configuration ---
client = OpenAI(
    base_url=os.environ["MODEL_URL"],
    api_key="not-needed",
)
MODEL = os.environ["MODEL_NAME"]

# --- Tool Definitions ---
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "Get the current weather for a location",
            "parameters": {
                "type": "object",
                "properties": {
                    "location": {"type": "string", "description": "City and state"},
                },
                "required": ["location"],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "lookup_employee",
            "description": "Look up an employee by name and return their department and title",
            "parameters": {
                "type": "object",
                "properties": {
                    "name": {"type": "string", "description": "Employee full name"},
                },
                "required": ["name"],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "check_inventory",
            "description": "Check inventory levels for a product by SKU or name",
            "parameters": {
                "type": "object",
                "properties": {
                    "product": {"type": "string", "description": "Product name or SKU"},
                },
                "required": ["product"],
            },
        },
    },
]

# --- Mock Tool Implementations ---
def get_weather(location: str) -> dict:
    data = {
        "Boston, MA": {"temp": 72, "condition": "partly cloudy"},
        "San Francisco, CA": {"temp": 61, "condition": "foggy"},
        "New York, NY": {"temp": 78, "condition": "sunny"},
    }
    return data.get(location, {"temp": 65, "condition": "unknown"})

def lookup_employee(name: str) -> dict:
    employees = {
        "Alice Johnson": {"department": "Engineering", "title": "Staff Engineer"},
        "Bob Smith": {"department": "Sales", "title": "Account Executive"},
        "Carol White": {"department": "HR", "title": "Benefits Coordinator"},
    }
    return employees.get(name, {"department": "unknown", "title": "unknown"})

def check_inventory(product: str) -> dict:
    inventory = {
        "laptop-15": {"in_stock": 42, "warehouse": "Austin"},
        "monitor-27": {"in_stock": 0, "warehouse": "Austin", "restock": "2 days"},
        "keyboard-mx": {"in_stock": 185, "warehouse": "Portland"},
    }
    return inventory.get(product.lower(), {"in_stock": -1, "error": "product not found"})

TOOL_FUNCTIONS = {
    "get_weather": get_weather,
    "lookup_employee": lookup_employee,
    "check_inventory": check_inventory,
}

# --- Tool Calling Loop ---
def run_query(user_message: str):
    print(f"\n{'='*60}")
    print(f"User: {user_message}")
    print(f"{'='*60}")

    messages = [{"role": "user", "content": user_message}]

    while True:
        response = client.chat.completions.create(
            model=MODEL,
            messages=messages,
            tools=tools,
            tool_choice="auto",
        )
        msg = response.choices[0].message

        if not msg.tool_calls:
            print(f"\nAssistant: {msg.content}")
            return msg.content

        messages.append(msg)

        for tc in msg.tool_calls:
            fn_name = tc.function.name
            fn_args = json.loads(tc.function.arguments)
            print(f"\n  -> Tool call: {fn_name}({fn_args})")

            result = TOOL_FUNCTIONS[fn_name](**fn_args)
            result_str = json.dumps(result)
            print(f"  <- Result: {result_str}")

            messages.append({
                "role": "tool",
                "tool_call_id": tc.id,
                "content": result_str,
            })

# --- Run Queries ---
run_query("What is the weather in Boston?")
run_query("Look up Alice Johnson and tell me her role.")
run_query("Do we have any laptop-15 units in stock?")
PYEOF
----

== Run the Application

Execute the script:

[source,bash,role="execute"]
----
python3 ~/tool_app.py
----

You should see the full loop for each query: the user message, the tool call the model makes, the mock result, and the final natural language answer.

Watch for these behaviors:

* The model selects the *correct tool* for each question
* It extracts *structured arguments* from the natural language query
* The final answer *incorporates the tool result* naturally

== Examine the Output

For the weather query, the model should call `get_weather` with `Boston, MA` and respond with the temperature and conditions. For the employee lookup, it should call `lookup_employee` with `Alice Johnson` and mention her title and department.

If a tool call fails or the model picks the wrong tool, that is still useful information -- it shows the boundary of the model's tool selection ability.
